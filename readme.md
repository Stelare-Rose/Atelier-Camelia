# Atelier Camelia
> Part of the Atelier (codename for personal usage) set of projects!  
## Overview
This is a quickshell configuration I use for my own personal setup.
> I do not recommend this to be used by others, or at least as it stands, this project is use-at-your-own-risk  
> Most of the code here was written by an LLM, as I wanted to get up and running ASAP to finally handle some weird quirks in my setup  
> As the project matures, this disclaimer will change. As for now, this project is use at your own risk.  

## Features
- Notifications
- Volume Control
- Brightness Control
- CPU, GPU, Network, RAM, Disk usage
- Calendar, Clock
- Launcher
- Clipboard

## Requirements
- Niri
- Nerd Font
- Quickshell (yea duh)

Packages:
- brightnessctl
- ddcutil
- upower
- pipewire + wireplumber
- pulseaudio
- libqalculate
- cliphist
- wl-clipboard
- intel-gpu-tools (If Intel)
- nvidia-smi (If Nvidia)
